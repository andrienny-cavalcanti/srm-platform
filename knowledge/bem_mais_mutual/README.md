# Base de conhecimento — Bem Mais Mutual

Coloque aqui somente materiais oficiais validados pela empresa, por exemplo:

- planos;
- coberturas;
- assistências;
- regiões de atendimento;
- tipos de veículos;
- regras oficiais;
- processo de cotação e contratação.

A IA deverá utilizar essa base para respostas comerciais e não deverá inventar informações.
